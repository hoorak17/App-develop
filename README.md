# App-develop
# Planner MVP

하루 계획 → 실행 → 최소 피드백 → 다음 계획 보정을 목표로 한  
개인용 경량 플래너 MVP 프로젝트입니다.

이 프로젝트는 “더 열심히”가 아니라  
**계획과 실제 행동의 차이를 줄이는 것**을 목표로 합니다.

---

## 현재 상태

- 버전: v1.1 (개인 사용 테스트 중)
- 플랫폼: Android
- 저장 방식: 로컬 메모리 (영구 저장 미구현)

---

## 개발 목적

- 계획 입력과 피드백이 실제로 귀찮지 않은지 검증
- 하루 단위 계획–실행–피드백 사이클이 지속 가능한지 확인
- 자기 과대평가를 줄이는 UX 실험
