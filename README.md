# App-develop  
# Planner MVP

하루 계획 → 실행 → 최소 피드백 → 다음 계획 보정을 목표로 한  
개인용 경량 플래너 MVP 프로젝트입니다.

이 프로젝트는 “더 열심히”를 강요하지 않습니다.  
**계획과 실제 행동 사이의 간극을 인식하고 줄이는 것**을 목표로 합니다.

---

## 현재 상태

- 버전: v1.2 (개인 실사용 테스트 중)
- 플랫폼: Android
- 저장 방식: 로컬 저장소 기반 (온라인 동기화 없음)

---

## 핵심 컨셉

- 하루 단위로만 생각한다  
- 계획은 가볍게, 실행은 현실적으로  
- 피드백은 “완벽”이 아니라 “기록 여부”에 의미를 둔다
- 다음 날 계획은 이전 하루의 결과를 기반으로 조정한다

---

## 주요 흐름

1. **홈 화면**
   - 오늘 날짜 기준 타임라인 표시
   - 일정별 실행 상태와 피드백을 한눈에 확인
2. **오늘 요약**
   - 하루 일정과 피드백 정리
   - 하루 종료 또는 다음 날 계획으로 이동
3. **내일 계획**
   - 어제 일정 복사 / 신규 추가 / 과거 기록 불러오기
4. **다음 날 진행**
   - 계획 확정 후 새로운 하루 시작

---

## 개발 목적

- 계획 입력과 피드백이 실제로 귀찮지 않은지 검증
- 하루 단위 계획–실행–피드백 사이클이 지속 가능한지 확인
- 자기 과대평가를 줄이는 UX 구조 실험
- “기록을 남기는 행위” 자체의 최소 비용화

---

## 설계 원칙

- 날짜 전환은 사용자의 명시적 행동을 기준으로 한다
- 피드백이 없는 일정도 하나의 기록으로 취급한다
- 내부 상태나 테스트용 정보는 사용자에게 노출하지 않는다
- 기능 추가보다 **흐름의 자연스러움과 안정성**을 우선한다

## 주의

이 프로젝트는 현재 **개인 실사용을 위한 MVP 단계**입니다.

- 기능 완성
- 외부 배포
- 수익화
- 데이터 동기화  

를 목표로 하지 않으며,  
실사용을 통해 설계와 UX를 검증하는 용도로만 운영됩니다.
