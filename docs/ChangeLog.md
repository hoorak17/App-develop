# 변경 기록 (Changelog)

## v1.1 – 홈 타임라인 및 상호작용 개선
2026-01-16

### 추가됨
- 홈 화면에 하루 전체 타임라인(00:00~24:00) 표시
- 빈 시간대 클릭 시 즉시 일정 추가 가능
- 휠(다이얼) 방식 시간 선택 UI 도입
- 일정 길게 누르면 수정 / 삭제 가능
- 일정당 복수 피드백 태그 선택 가능
- 피드백에 1줄 메모 입력 기능 추가
- 홈 화면 상단에 오늘 날짜 표시

### 변경됨
- 앱 흐름을 `홈 → 오늘 요약 → 내일 계획 → 홈` 구조로 수정
- 30분 단위 분할 표시 제거, 일정은 하나의 블록으로 표시
- 요약 화면에서 피드백 개수 집계 방식 제거  
  → 일정별 피드백 내용 중심 구조로 변경

### 수정됨
- 어제/내일 일정이 날짜 기준으로 꼬이던 문제 해결
- 자정(00:00) 경계에서 일정 종료 시간 인식 오류 수정
- 일정 간 겹침 처리 로직 정비
- 터치/롱프레스 이벤트 충돌 문제 수정

### 알려진 문제
- 데이터 영구 저장 미구현 (앱 종료 시 초기화됨)

## v1.2 – 하루 종료 흐름 및 기록 안정화
2026-01-20

### 추가됨
- 하루를 **수동으로 종료**할 수 있는 기능 추가  
  → 오늘을 종료하고 다음 날로 이동
- 하루 종료 시:
  - 오늘 일정은 자동으로 기록(히스토리) 보관
  - 내일 일정이 있으면 바로 홈으로 이동
  - 내일 일정이 비어 있으면 계획 화면으로 자동 이동
- 하루 종료 전 확인 다이얼로그 추가  
  → 실수로 날짜를 넘기는 것을 방지
- 모든 기록을 **초기 상태로 되돌리는 전체 초기화 기능** 추가  
  → 2단계 경고 후 실행

### 변경됨
- 날짜 전환(다음 날 이동) 로직을 **중앙에서 일괄 처리**하도록 구조 개선  
  → 화면 간 이동과 데이터 상태 불일치 문제 해결
- 홈 화면은 **날짜와 일정 개수만 표시**하도록 단순화  
  → 테스트·내부 상태 관련 정보 제거
- 개발자 모드는 **수동 테스트 전용 기능**으로 분리  
  → 일반 사용자에게는 노출되지 않음

### 수정됨
- 앱 최초 실행 시 홈 화면이 비어 보이던 문제 수정  
  → 초기 데이터 로딩 시점 안정화
- 홈 화면에서 일정 피드백이 즉시 반영되지 않던 문제 수정
- 날짜가 바뀌어도 이전 하루 일정이 남아 있던 문제 해결
- 강제 하루 종료 후 화면 흐름이 어색하던 문제 개선  
  → 자연스러운 사용자 흐름으로 정리

### 설계 결정 사항
- 날짜 변경은 **사용자 명시적 동작**(하루 종료)에 의해서만 발생
- 피드백이 없는 일정은 “미입력” 상태로 자동 기록
- 수면 기반 자동 날짜 전환 로직은 추후 버전에서 검토

### 알려진 제한
- 모든 데이터는 로컬 저장소 기반
- 주/월 단위 통계 및 온라인 동기화 기능 미제공
