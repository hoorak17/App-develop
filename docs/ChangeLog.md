# 변경 기록 (Changelog)

## v1.1 – 홈 타임라인 및 상호작용 개선
2026-01-16

### 추가됨
- 홈 화면에 하루 전체 타임라인(00:00~24:00) 표시
- 빈 시간대 클릭 시 즉시 일정 추가 가능
- 휠(다이얼) 방식 시간 선택 UI 도입
- 일정 길게 누르면 수정 / 삭제 가능
- 일정당 복수 피드백 태그 선택 가능
- 피드백에 1줄 메모 입력 기능 추가
- 홈 화면 상단에 오늘 날짜 표시

### 변경됨
- 앱 흐름을 `홈 → 오늘 요약 → 내일 계획 → 홈` 구조로 수정
- 30분 단위 분할 표시 제거, 일정은 하나의 블록으로 표시
- 요약 화면에서 피드백 개수 집계 방식 제거  
  → 일정별 피드백 내용 중심 구조로 변경

### 수정됨
- 어제/내일 일정이 날짜 기준으로 꼬이던 문제 해결
- 자정(00:00) 경계에서 일정 종료 시간 인식 오류 수정
- 일정 간 겹침 처리 로직 정비
- 터치/롱프레스 이벤트 충돌 문제 수정

### 알려진 문제
- 데이터 영구 저장 미구현 (앱 종료 시 초기화됨)
