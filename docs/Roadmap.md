# Roadmap

본 문서는 향후 버전에서 **추가·개선·검토할 기능 범위**를 정리한다.  
모든 항목은 구현 확정이 아닌 계획 수준이며, 상황에 따라 변경될 수 있다.

---

## v1.3 (단기 확장)

### 목표
- 기존 구조를 유지한 상태에서 보조 기능 확장
- GPT 기능의 최소 단위 검증

### 계획 항목
- GPT 기반 일정 제목 해석
  - 자유 텍스트 일정명 → 피드백 블록 추천
  - 명확한 키워드는 로컬 룰 우선 처리
- 주간 요약 문장 생성 (선택)
  - 수치 계산은 로컬 처리
  - 문장 표현만 GPT 사용
- GPT 결과 캐싱
  - 동일 입력 반복 호출 방지
- 하루 종료 이후 간단한 요약 문구 표시

### 제외
- GPT 기반 자동 계획 수정
- GPT 전면 의존 구조

---

## v1.4 (중기 개선)

### 목표
- 기록 누적 시 체감되는 사용성 개선

### 계획 항목
- 주간 리뷰 전용 화면
- 피드백 블록 사용 빈도 기반 추천 가중치
- 반복 일정(루틴) 관리 UI 개선
- 기록 탐색 UX 개선
  - 날짜 이동
  - 최근 기록 빠른 접근

---

## v1.5 (안정화)

### 목표
- 구조 안정화 및 기술 부채 정리

### 계획 항목
- Room DB 마이그레이션 정비
- 데이터 초기화 / 백업 흐름 정리
- 날짜 전환 및 하루 종료 테스트 보강
- 내부 상태 관리 로직 정리

---

## v2.0 (장기 검토)

※ 필수 목표 아님
