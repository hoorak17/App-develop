# MVP 명세서 (MVP Spec v1.2)

## 1. 제품 한 줄 정의 (One-liner)
> 이 앱은 대학생·자기관리형 사용자가 일상적인 공부·운동·작업 계획을 세우고 실행하는 과정에서  
> 계획과 실제 행동의 차이를 최소 입력·최소 피드백으로 기록하고,  
> 다음 계획을 더 현실적으로 보정하도록 돕는 **경량 계획·피드백 기록 도구**다.

---

## 2. 해결하려는 문제 (Problem Statement)
- 계획은 세우지만 실제 실행과 자주 어긋난다
- 반복적인 실패로 본인의 현실적인 수행 한계를 파악하기 어렵다
- 회고·피드백의 필요성은 알지만 텍스트 기록은 부담스럽다
- 매일 계획을 처음부터 작성하는 과정이 귀찮아 서비스가 지속되지 않는다

※ 본 MVP의 목적은 기능 완성도가 아니라,  
**계획–실행–피드백–보정 사이클이 실제로 지속 가능한지**를 검증하는 데 있다.

---

## 3. 타겟 사용자 (Target User)
- 시험·과제·운동·개인 프로젝트를 병행하는 대학생
- 기존 생산성 앱에서 기록 부담으로 이탈한 사용자
- 자신의 한계를 데이터로 인식하고 계획 정확도를 점진적으로 높이고 싶은 사용자

---

## 4. 핵심 가치 제안 (Core Value Proposition)
- 계획 실패를 실패가 아닌 **다음 계획을 위한 보정 데이터**로 취급
- 입력·피드백 과정에서 발생하는 귀찮음을 구조적으로 제거
- 기록은 최소화하고, 계획 수정에 필요한 정보만 남김

---

## 5. MVP 기능 목록 (v1.2 기준)

| 번호 | 기능명 | 설명 | 포함 이유 |
|----|------|----|----|
| 1 | 다음날 계획 생성 | 디폴트 루틴 템플릿이 자동 적용된 상태로 다음날 계획 생성 | 계획 입력 부담 제거 |
| 2 | 실행 후 블록식 피드백 | 사전 정의된 블록 선택으로 즉시 피드백 기록, 1줄 메모 선택 | 기록 시간 최소화 |
| 3 | 하루 종료 및 기록 | 사용자가 명시적으로 하루를 종료하여 기록 확정 | 날짜 혼선 방지 |
| 4 | 실행 결과 요약 | 하루 단위로 계획 대비 수행 결과 요약 표시 | 편차 인식 |
| 5 | 기록 누적 조회 | 날짜 단위 기록 열람 (통계 최소화, 요약 중심) | 자기 패턴 인식 |

---

## 6. 계획 작성 방식 (핵심 설계 원칙)
- **디폴트 계획(루틴 템플릿) 자동 적용**
  - 수면, 등교/출근, 수업/근무, 식사 등 기본 루틴 포함
- 다음날 계획 화면 진입 시:
  - 템플릿이 채워진 상태로 시작
  - 사용자는 추가·삭제·수정만 수행
  - 아무 조작이 없으면 디폴트 계획 그대로 확정

---

## 7. 하루 종료 흐름 (v1.2 핵심 설계)
- 날짜 변경은 **사용자 명시적 동작(하루 종료)**으로만 발생
- 하루 종료 시:
  - 오늘 일정은 자동으로 히스토리에 기록
  - 내일 일정이 존재하면 홈으로 이동
  - 내일 일정이 비어 있으면 계획 화면으로 이동
- 종료 전 확인 다이얼로그 제공 (오작동 방지)

---

## 8. 추천 기능 범위 (MVP 기준)
### 포함
- 시간대 추천 (룰 기반)
- 작업 순서 추천 (룰 기반)

### 제한 조건
- 자동 강제 배치 없음
- 모든 추천은 선택 사항

---

## 9. 추천 로직 및 AI(GPT) 사용 기준
- 기본 로직: **룰 기반**
  - 최근 기록 기준 완료율·준수율 활용
- AI(GPT) 사용 범위:
  - 일정 제목 해석
  - 피드백 블록 선택 보조
  - 하루/주간 요약 문장 생성
- AI는 판단·계산·강제 로직에 관여하지 않음

---

## 10. 피드백 방식
- 블록식 피드백 (고정 세트)
- 일정당 복수 선택 가능
- 텍스트 회고는 선택 사항 (최대 1줄)

---

## 11. 하지 않는 것 (Non-Goals)
- 피드백 블록 개인화
- 자유 텍스트 회고 분석
- AI 자동·강제 추천
- 자동 날짜 전환
- 통계 그래프, 랭킹, 비교
- 협업·공유 기능
- 유료화 요소

---

## 12. 기술 범위 (Tech Scope)
- 플랫폼: Android
- 저장 방식: 로컬 저장소
- 네트워크: 기본 오프라인
- 외부 API: GPT API (선택적, 보조 역할)

---

## 13. 성공 기준 (Success Criteria)
- 하루 종료 흐름이 혼란 없이 자연스러운지
- 피드백 입력이 부담스럽지 않은지
- 며칠 연속 사용해도 거부감이 없는지

---

## 14. 제1목표
> 이 앱의 제1목표는 생산성을 극대화하는 것이 아니라,  
> **계획 → 실행 → 최소 피드백 → 명시적 하루 종료 → 다음 계획 보정**의 사이클이  
> 실제 사용자 환경에서 지속 가능한지를 검증하는 것이다.
